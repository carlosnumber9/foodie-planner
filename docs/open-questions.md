# Open questions

## Food catalog placement

R1 requires food browsing and maintenance, but the agreed primary navigation lists Recipes, Calendar, Inventory, Shopping, and More without defining where the food catalog lives. Should it live under More or Settings, be reached contextually from recipe and inventory workflows, or become a primary destination? This blocks only the final food-catalog navigation and visual composition; domain, API, and standalone form work can continue.

## Curated Ciqual import

Which Ciqual 2025 source artifact, common-food selection criteria, Spanish translation review, and final attribution wording should be approved before implementing the import? The schema supports curated source identifiers and versions, but no dataset transformation or catalog data has been invented.

## Visual preset

Which user-supplied shadcn/ui preset should establish the final component system? The repository currently contains only proportional foundation styling and temporary semantic icon and PWA placeholders.
