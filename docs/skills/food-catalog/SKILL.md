# Maintain catalog foods

Read [the shared catalog authoring workflow](../../catalog-authoring.md), then inspect relevant food records and the linked schema. Reuse an existing matching food before proposing a duplicate. Preserve its immutable measurement type and exact nutrition reference amount.

Present readable food/source/nutrition proposals and resolve missing label values before acceptance. Never invent nutrition or attribution. Incorporate only accepted content; append revisions and retain earlier data. Follow the shared validation and reporting steps. Catalog acceptance alone never authorizes commit, push, or publication.
